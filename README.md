# Kintrist website

Static site for Kintrist (family advocacy, Tri-Cities WA). Plain HTML and CSS, no build step.

- `index.html`, `services.html`, `about.html`, `contact.html`, `privacy.html`: the pages
- `styles.css`: all styling (River & Sage palette, Fraunces + Inter)
- `favicon.svg`: browser icon

## Hosting
Cloudflare Pages, connected to this GitHub repository. Build command: none. Output directory: `/`.
Domain: kintrist.com (registered at Cloudflare).
